# Create a Financial Report

## Overview

You can create a financial report to review financial data for a selected period.

## Prerequisites

- You must have access to FinanceFlow.
- You must have permission to create financial reports.

## Procedure

1. Sign in to FinanceFlow.
2. Open **Reports** from the main navigation.
3. Select **Create Report**.
4. Enter a report name.
5. Select the reporting period.
6. Choose the required financial data.
7. Select **Save**.

## Expected Result

The report is saved and appears in the Reports list.

## Troubleshooting

**Problem:** The Create Report option is unavailable.

**Solution:** Verify that your account has permission to create reports. Contact your administrator if the issue persists.
